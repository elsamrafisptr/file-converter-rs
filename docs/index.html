Why File Converter?

Two clicks

No app to open, no website to upload to. Right-click your files and pick the format you want.

Works everywhere

The same tool on Windows, macOS and Linux, with more than 70 ready-made presets.

Free and private

No ads and no tracking. Your files never leave your computer. The code is open source (GPL v3).

Get it

Choose your system. The download page has step-by-step install help.

Windows macOS Linux

File Converter uses free tools to do the work: ffmpeg (video and audio), ImageMagick (images), Ghostscript (PDF pages) and LibreOffice (Word, Excel and PowerPoint). If one is missing, the File Converter app tells you and shows the command to install it.

How to use it

Select

Select one or more files in your file manager.

Right-click

Open File Converter in the menu.

Choose

Click a preset, for example To Mp4. Wait for the message that it is done.

WhereWhere to find the menu
Windows 11Right-click › Show more options › File Converter
Windows 10Right-click › File Converter
Linux (Dolphin)Right-click › File Converter
Linux (Files / Nautilus)Open the File Converter app once. Then right-click › Scripts › File Converter
macOS (Finder)Right-click › Quick Actions › File Converter…, then choose a preset in the list

The new file is saved next to the original, with the same name. File Converter never overwrites a file: if video.mp4 already exists, you get video (2).mp4.

Change the menu

Open the settings with Configure presets… at the bottom of the File Converter menu, or open the File Converter app from the Start menu, the app menu or Applications.

Presets

Add, copy, delete, reorder and search presets. Put a / in the name to make a sub-menu, like Small/To Mp4. Save with Ctrl+S (⌘S on a Mac).

File types

Tick the file types a preset should appear on. Untick them to hide it from the menu.

Quality

Change the quality, size, rotation, audio bitrate and more. Experts can type their own ffmpeg options.

Click Save and update context menu to apply your changes. Restore defaults brings back the original presets.

Output file name

Each preset has a name pattern. The default (p)(f) means “same folder, same name”. Some useful parts:

PartMeaningExample
(p)Folder of the original file/home/me/Videos/
(f)Name of the original fileholiday
(i)Old file extensionmov
(p:v)Your Videos folder ((p:m) Music, (p:p) Pictures, (p:d) Documents)(p:v)(f)

Example: (p)converted/(f) puts the new files in a “converted” folder next to the originals.

Help

I do not see File Converter in the right-click menu

Windows 11: click Show more options first. Linux: close and open your file manager again. With Files (Nautilus), open the File Converter app once. macOS: open the File Converter app once. Then open System Settings, search for Extensions, and turn on File Converter… under Finder.

The menu only shows the presets that fit all selected files. Select files of the same type.

Nothing happens when I click “Configure presets…”

Update to version 0.1.2 or newer. Older versions did not open the settings from the Dolphin menu on Linux. You can always open the File Converter app from the app menu instead.

The app says “Not installed: …”

One of the free converter tools is missing. Click Copy next to the command, paste it into a terminal and run it. Then click Check again.

macOS says the app “cannot be opened”

The app is not signed by Apple. Right-click it in Applications and choose Open, then Open again. If that does not work, go to System Settings › Privacy & Security and click Open Anyway.

Windows says “Windows protected your PC”

The installer is not signed yet. Click More info, then Run anyway.

Word, Excel or PowerPoint files do not convert

Install LibreOffice (free). On Windows, you can also run the File Converter installer again and tick the LibreOffice box.

A conversion failed

You get a message with the reason. Make sure the file opens in a normal player or viewer. If it still fails, report the problem on GitHub and include the message.

How do I uninstall it?

Windows: Settings › Apps › File Converter › Uninstall. Ubuntu/Debian: sudo apt remove file-converter. Other Linux: ./install.sh --uninstall. macOS: run the command below, then move the app to the Trash.

"/Applications/File Converter.app/Contents/MacOS/file-converter" uninstall
Can I use it from the terminal? 
file-converter list                         # show all presets
file-converter convert --preset "To Mp4" a.mov b.avi
file-converter settings                     # open the settings window
