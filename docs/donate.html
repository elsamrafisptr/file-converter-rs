Support File Converter

File Converter is free, open source and has no ads or tracking. If it saves you time, you can help keep it going.

Donate

Your support pays for the time spent fixing bugs, adding new formats and keeping the installers working on every system. Any amount helps, one time or every month.

Sponsor on GitHub

You can pay with a card or PayPal, one time or every month.

Give a star

A star on GitHub helps other people find File Converter.

Write code

Fixes and new presets are welcome. Read the contributing notes, then open a pull request.

Say thanks

A short message means a lot. Say hello on the developer's GitHub profile.
