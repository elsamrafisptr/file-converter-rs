Windows

Windows 10 or 11, 64-bit.

Download for Windows (60 MB)
  1. Open file-converter-setup-x64.exe.
  2. If Windows says “Windows protected your PC”, click More info, then Run anyway. This happens because the installer is not signed yet.
  3. Click Next until it is done. You do not need admin rights.
  4. Optional: tick Ghostscript (to turn PDF pages into images) and LibreOffice (for Word, Excel and PowerPoint files). The installer downloads them for you.

Done! Right-click a file and open File Converter. On Windows 11, click Show more options first. ffmpeg and ImageMagick are included, so video, audio and images work right away.

macOS

macOS 11 (Big Sur) or newer. Works on Apple Silicon and Intel Macs.

Download for macOS (8 MB)
  1. Open file-converter-macos.dmg and drag File Converter into Applications.
  2. Open Applications, right-click File Converter and choose Open. Click Open again. You only do this the first time, because the app is not signed by Apple.
  3. Install the converter tools with Homebrew. Open Terminal and paste: 
    brew install ffmpeg-full imagemagick ghostscript
  4. Optional, for Word, Excel and PowerPoint files: brew install --cask libreoffice

Done! In Finder, right-click a file › Quick Actions › File Converter… and choose a preset. Do not see it? Open System Settings, search for Extensions and turn on File Converter… under Finder.

Linux

64-bit (x86_64). Works with Dolphin (KDE) and Files/Nautilus (GNOME).

Ubuntu, Kubuntu, Debian, Linux Mint, Pop!_OS

Download .deb (4.5 MB)

Double-click the file to install it, or run this in a terminal in your Downloads folder:

sudo apt install ./file-converter_0.1.2-1_amd64.deb

This also installs ffmpeg, ImageMagick and Ghostscript. For Office files, add sudo apt install libreoffice.

Fedora, Arch, openSUSE and others

Download .tar.gz (6.5 MB)

Unpack it and run the installer. It installs for your user only (no root needed):

tar -xzf file-converter-linux-x86_64.tar.gz
cd file-converter
./install.sh

Then install the converter tools with your package manager, for example sudo dnf install ffmpeg ImageMagick ghostscript on Fedora (ffmpeg comes from RPM Fusion) or sudo pacman -S ffmpeg imagemagick ghostscript on Arch.

Done! Right-click a file › File Converter (Dolphin). With Files/Nautilus, open the File Converter app once, then use right-click › Scripts › File Converter.

Other ways

Older versions

All versions are on the GitHub releases page. See the changelog for what changed.

Build it yourself

You need Rust. Then run:

git clone https://github.com/elsamrafisptr/file-converter-rs
cd file-converter-rs
cargo install --path .
file-converter install
